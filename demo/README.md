Chat demo for BSBA-21-Bantwal, a 4B open model adapted to Mangalorean Konkani as it is spoken (Kannada script).
Model card: https://huggingface.co/decentmakeover/bsba-21-bantwal-konkani-4b. Code: https://github.com/DecentMakeover/bsba-21-bantwal-konkani-4b.

Replies are capped at 256 tokens, the last 4 exchanges are kept as context, and each visitor gets 20 replies an hour.
Conversations are not stored.
